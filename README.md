```markdown
# 🚗 LuxuryCarHub – Car Dealer Platform (Web)

A full-featured car dealership web application where users can browse vehicles and dealers can manage listings.

💻 GitHub: https://github.com/pasindunavodya01/LuxuryCarHub_Laravel  

---

## ✨ Features

- User & Dealer roles with separate dashboards  
- Authentication using Laravel Jetstream  
- Add, edit, delete vehicle listings  
- Dealer profiles with listed vehicles  
- Image upload and storage system  
- REST API support for mobile app integration  

---

## 🛠 Tech Stack

- Backend: Laravel 12, Livewire  
- Database: MySQL (auth), MongoDB (vehicle data)  
- Frontend: Tailwind CSS  
- API Testing: Postman  

---

## 🚀 How It Works

- Dealers manage vehicle listings  
- Users browse and connect with dealers  
- Mobile app consumes API endpoints  

---

```bash
